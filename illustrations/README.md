## Как заменить или добавить рисунок

Положите файл в эту папку и укажите его в `attractions.json` в поле `"illustration"` у нужной точки. Если поля нет, скрипт ищет файл по шаблону `NN-*.svg`, где `NN` — номер точки.

Подойдёт:
- SVG в стиле ниже;
- PNG с прозрачным фоном, например от иллюстратора.

Отключить рисунки на карте: `SHOW_ILLUSTRATIONS = False` в `generate_map.py`. Можно и для одного стиля — в `STYLES`.

## Стиль (чтобы новые рисунки не выбивались)

**Холст.** `viewBox="0 0 200 200"`, прозрачный фон. Объект стоит основанием около точки (100, 180) и заполняет холст. Первым элементом идёт мягкая тень:

```xml
<ellipse cx="100" cy="182" rx="…" ry="10…14" fill="#3B2A1A" opacity="0.18"/>
```

**Ракурс.** Вид 3/4 сверху, как на туристической карте:
- фасад рисуется плоско;
- правая боковая грань уходит вверх-вправо по вектору (0,87·d; −0,5·d);
- крыши видны сверху.

**Свет.** Сверху слева. Фасад — базовый цвет, боковая грань — на ~20 % темнее, крыша — светлее. Без градиентов: 2–3 плоских тона на материал.

**Обводка.** У всех фигур `stroke="#3B2A1A"`, толщина 2 у крупных форм и 1,2 у деталей, `stroke-linejoin="round"`.

**Палитра** (фасад / бок):

| Материал | Фасад | Бок |
|---|---|---|
| кремовая стена | `#F4E6C8` | `#D9C6A0` |
| охра | `#EFC66A` | `#CFA24A` |
| белый декор | `#FFF8EC` | `#E2D8C6` |
| кирпич | `#C65A3E` | `#A3452E` |
| зелёная кровля | `#6E9E5F` | `#557E48` |
| серая кровля | `#8C9DAE` | `#6D7F92` |
| золото | `#E9B53A` | `#C08F22` |
| бронза | `#5A4A3A` | `#8C7457` |
| зелень | `#7FB069` | `#5E8D4E` |

Окна — `#4E6E91` с бликом `#A9CBEA`.

**Нельзя:** `defs`, `id`, градиенты, фильтры, маски, `clipPath`, `<style>`, `class`. Текст — только если без него никак, со шрифтом `'DejaVu Sans', Verdana, 'PT Sans', Arial, sans-serif`.

**Проверка.** Рисунок должен узнаваться при 160 px. Посмотреть его можно так:

```bash
DYLD_FALLBACK_LIBRARY_PATH=/opt/homebrew/lib .venv/bin/python -c "import cairosvg; cairosvg.svg2png(url='illustrations/05-kalancha.svg', write_to='check.png', output_width=400, output_height=400, background_color='#DCC6A0')"
```

`DYLD_FALLBACK_LIBRARY_PATH` нужен только на macOS с cairo из Homebrew.
